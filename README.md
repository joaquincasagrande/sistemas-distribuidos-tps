## 📌 Alcance y Propósito del Repositorio

El presente repositorio consolida las implementaciones prácticas, simulaciones distribuidas, laboratorios de infraestructura y pruebas de concepto (PoC) desarrolladas a lo largo de la asignatura **Sistemas Distribuidos**.
### Delimitación de Contenido
1. **Enfoque Práctico:** Este espacio almacena **únicamente el código fuente, archivos de configuración, scripts de compilación y orquestación con Docker Compose** correspondientes a los trabajos prácticos y casos de estudio que requieren implementación.

2. **Documentación Teórica:** Las respuestas a los cuestionarios conceptuales e informes _teóricos_ no se encuentran en este repositorio.

3. **Excepción de Entrega — TP8 (Servicios con Apache Kafka):**
   Por requerimientos formales de entrega y la complejidad de su arquitectura basada en microservicios desacoplados (NestJS, React, MongoDB y Apache Kafka), el **Trabajo Práctico N° 8** se encuentra alojado en su propio repositorio independiente: https://github.com/joaquincasagrande/TP8-Activacion-de-Servicios-con-Kafka
